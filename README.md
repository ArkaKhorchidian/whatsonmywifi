# whatsonmywifi

**There are more things on your WiFi than you think, and some of them are telling everyone who you are.** whatsonmywifi lists every device on your network, works out what each one is (TV, camera, speaker, smart plug, phone, mystery box), and shows what they give away: owners' names, open video streams, telnet, a router that lets any gadget open itself to the internet.

```bash
uvx whatsonmywifi
```

No root, no install, no account. Nothing leaves your network.

## What it checks

| | |
|---|---|
| **Names that give you away** | "Jordan's iPhone", `Jordans-MacBook-Pro`: everyone on the WiFi sees whose devices are there |
| **Cameras and video streams** | RTSP streams often have no password or the default one |
| **Telnet** | plain-text logins, the way botnets like Mirai take over cameras and routers |
| **UPnP on the router** | any device can open itself to the internet without asking you |
| **Remote control** | VNC or Remote Desktop listening on something that isn't a computer |
| **Router admin without HTTPS** | your router password crosses the WiFi unencrypted |
| **Smart devices next to your laptop** | a hacked plug can reach everything else on the same network |
| **Devices that won't say what they are** | check these against your router's device list |

## How it works

Everything is ordinary traffic your computer is allowed to send without admin rights:

1. **ARP**: one empty UDP packet to each address in your subnet makes your computer ask "who has this IP?", and the answers land in its ARP table. MAC addresses give the maker (from the IEEE registry, via [netaddr](https://github.com/netaddr/netaddr)).
2. **Bonjour (mDNS)**: asks for AirPlay, Chromecast, printers, HomeKit, Sonos, Hue, Matter and other services. Devices answer with their names and models.
3. **UPnP (SSDP)**: TVs, routers and speakers describe themselves: name, maker, model.
4. **Reverse DNS**: most routers hand out names from DHCP.
5. **Ports**: a quick TCP connect to 16 well-known ports per device (SSH, telnet, RTSP, VNC, printing…). `--no-ports` skips it.

Only scan networks you own or are allowed to test. On public and office WiFi, client isolation usually hides other devices anyway.

## Options

```
whatsonmywifi              # your /24
whatsonmywifi --prefix 22  # a bigger network
whatsonmywifi --no-ports   # skip the port check
whatsonmywifi --json       # for scripts
```

## Install

```bash
uvx whatsonmywifi           # run without installing
pipx install whatsonmywifi  # or install it
```

Requires Python 3.9+. Dependencies: `rich` and `netaddr`. macOS, Linux and Windows.
